# Example form: 026-LE221, Security Screening Check

Published by the Ontario Provincial Police in the Central Forms Repository.

- Form page: https://forms.mgcs.gov.on.ca/en/dataset/026-le221
- English PDF: https://forms.mgcs.gov.on.ca/dataset/db43f6d7-e987-4173-96cc-c6b6b9d90d78/resource/52e30a5f-424f-4425-8545-27f8d089cae2/download/le221e.pdf

Download the PDF, save it here as `form.pdf` and open it in Adobe Acrobat Reader.
It does not open in a browser.

`outline.md` was created from the English PDF with `tools/extract-form` on 18 November 2026.

## Why this form is a good exercise

- Three parties complete it: the applicant, the requesting organization and the police.
  Only the applicant's sections belong in the web form.
- The address block repeats: addresses for the last five years.
- One field depends on another: the driver's licence number is enabled only when a
  driving-history check is selected.
- It has signatures, which a web form has to replace.
- No field is flagged as mandatory in the form definition. The form's scripts decide.

The form is long. For the lab, build the applicant information, the addresses and the consent sections.
